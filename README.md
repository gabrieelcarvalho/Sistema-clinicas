# 🏥 Sistema de Clínicas

Sistema de gerenciamento de clínicas desenvolvido em **Python**, com foco em **Programação Orientada a Objetos (POO)** e arquitetura **MVC**. A aplicação funciona pelo terminal e permite organizar cadastros, atendimentos e pagamentos.

## 🚀 Funcionalidades

- Cadastro e gerenciamento de clínicas, pacientes e profissionais.
- Cadastro de tipos de atendimento e procedimentos.
- Agendamento, reagendamento e cancelamento de consultas.
- Verificação de horários da clínica e conflitos na agenda de pacientes e profissionais.
- Validação de acompanhante para pacientes menores de idade.
- Pagamentos em **dinheiro, Pix e cartão**, incluindo pagamentos parciais.
- Relatórios de atendimentos e procedimentos.

## 🛠️ Tecnologias e conceitos

- **Python**
- **Programação Orientada a Objetos:** herança, encapsulamento, polimorfismo e classes abstratas.
- **MVC (Model–View–Controller)**
- **Tratamento de exceções personalizadas**

## ▶️ Como executar

Clone o repositório e entre na pasta do projeto:

```bash
git clone https://github.com/joserogeriorachadel-design/Sistema-clinicas.git
cd Sistema-clinicas
```

Execute a aplicação:

```bash
python main.py
```

> Não é necessário instalar bibliotecas externas. Os dados são armazenados em memória durante a execução.

## 📁 Estrutura do projeto

```text
Sistema-clinicas/
├── controller/   # Regras e fluxos do sistema
├── model/        # Classes e entidades
├── view/         # Menus e entrada de dados
├── exceptions/   # Exceções personalizadas
└── main.py       # Inicialização
```

## 🎯 Objetivo

Projeto acadêmico voltado à aplicação prática de **POO**, **MVC** e regras de negócio em um sistema de gerenciamento de clínicas.
